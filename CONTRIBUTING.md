# Contributing to CoCreate Disk

Please submit changes and issues through the
[CoCreate Disk repository](https://github.com/CoCreateJS/disk).

Before changing the public contract, update the [API specification](specifications/api.md)
and [architecture specification](specifications/architecture.md). Keep the
server and browser implementations aligned on operation names and return values.

Use semantic commit messages so automated release tooling can determine the
appropriate version change. Do not commit generated files or local storage data.
